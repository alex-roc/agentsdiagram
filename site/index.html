See your AI agents.

agentsdiagram reads the code of your PydanticAI and smolagents agents and draws them: agents, tools, toolsets, MCP servers, capabilities, delegation, hand-off workflows and pydantic-graph flows. Your code is parsed, never run.

$ uvx agentsdiagram scan . -f html -o agents.html

How it works

agentsdiagram is static analysis. It parses your Python files with LibCST and looks for the constructs each framework uses to declare agents, tools and their wiring. Nothing is imported or executed: no API keys, no dependencies of your project, no network.

The result is a small, versioned JSON graph. The CLI turns it into Mermaid, Markdown or a self-contained HTML page; the VS Code extension keeps it next to your code and redraws it as you type.

Anything that only exists at runtime, like tools fetched from a server or lists built in a loop, shows up as a dashed dynamic node instead of silently disappearing.

The code stays the source of truth. The diagram is drawn from it on every scan and on every keystroke in VS Code; there is no second model to keep in sync.

Get it

  1. Run it once, nothing to install

    With uv, from the root of your project:

    $ uvx agentsdiagram scan .

    Prints Mermaid. Add -f html -o agents.html for the interactive page, -f markdown for GitHub, or run agentsdiagram check . in CI.

  2. Keep it next to your code

    The Agents Diagram extension shows a live diagram that follows your edits, with “Show in diagram” code lenses and diagnostics. It runs the CLI through uv.

    VS Code Marketplace Open VSX

    Open VSX covers Cursor, Windsurf and Positron.

  3. Or install the CLI

    $ uv tool install agentsdiagram

    Also on PyPI (pip install agentsdiagram). Python 3.11+.
