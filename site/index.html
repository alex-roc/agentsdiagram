See, plan and edit your AI agents.

agentsdiagram reads the code of your smolagents and PydanticAI agents and draws them: agents, tools, MCP servers, managed agents, delegation, workflows and flows. Then it works the other way round: plan agents and tools in the diagram and they are written to your code. Static analysis: your code is parsed, never run.

$ uvx agentsdiagram serve

Plan and edit, in the diagram

Plan. Sketch a system before you write it. Plan agent and Add tool write planned stubs to your files: typed, documented, importable, and drawn dashed until you implement them. agentsdiagram check lists what is left.

Edit. Hand work from one agent to another, add an MCP server, change a model or the instructions, disconnect or remove. In smolagents that means managed_agents, @tool stubs and MCPClient; in PydanticAI, delegation tools, MCPToolset and Agent Specs.

Safe. Changes are made with LibCST: the rest of the file keeps its formatting, imports land where they belong, and in VS Code everything can be undone. Edits are refused if the code changed since the diagram was drawn.

$ agentsdiagram edit connect lead analyst

How it works

agentsdiagram is static analysis. It parses your Python files with LibCST and looks for the constructs each framework uses to declare agents, tools and their wiring. Nothing is imported or executed: no API keys, no dependencies of your project, no network.

The result is a small, versioned JSON graph. The CLI turns it into Mermaid, Markdown or a self-contained HTML page; serve and the VS Code extension keep it live and redraw it as you type. Edits made on the graph go back through the same pipeline as minimal changes to your files.

Anything that only exists at runtime, like tools fetched from a server or lists built in a loop, shows up as a dashed dynamic node instead of silently disappearing.

The code stays the source of truth. The diagram is drawn from it on every scan and every keystroke, and edits are written to it; there is no project file and no second model to keep in sync.

Get it

  1. Run it once, nothing to install

    With uv, from the root of your project:

    $ uvx agentsdiagram scan .

    Prints Mermaid. Add -f html -o agents.html for the interactive page, -f markdown for GitHub, run agentsdiagram serve for a live, editable diagram, or agentsdiagram check . in CI.

  2. Keep it next to your code

    The Agents Diagram extension shows a live diagram that follows your edits, lets you plan and edit from it (with undo), and adds “Show in diagram” code lenses and diagnostics. It runs the analyzer through uv.

    VS Code Marketplace Open VSX

    Open VSX covers Cursor, Windsurf and Positron.

  3. Or install the CLI

    $ uv tool install agentsdiagram

    Also on PyPI (pip install agentsdiagram). Python 3.11+.
